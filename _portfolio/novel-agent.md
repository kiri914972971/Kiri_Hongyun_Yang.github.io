## 项目定位

**Novel Agent** 是一个 **VS Code AI 小说创作助手**，面向需要长期维护世界观、人物设定、章节正文和创作灵感的长篇小说创作者。

GitHub: [kiri914972971/novel-agent](https://github.com/kiri914972971/novel-agent)

---

## 目标用户

- 长篇小说创作者
- 需要管理复杂设定、人物关系和章节结构的写作者
- 希望在写作环境中直接使用 AI 辅助创作的人

---

## 核心痛点

长篇写作中，创作者经常会遇到这些问题：

- 写作时需要在编辑器、AI 工具、设定文档之间频繁切换
- 通用 AI 对作品上下文记忆不足，容易忘记人物设定、世界观和前文细节
- 每次提问都需要反复解释背景，打断创作节奏
- 长文本续写和润色需要结合局部章节与全局设定，但普通对话很难稳定做到

Novel Agent 希望把 AI 能力嵌入创作者原本的写作环境中，让 AI 更懂作品上下文，也更贴近真实写作流程。

---

## 核心功能

- **知识库管理**：管理世界观、人物设定、剧情线、地点和风格说明
- **正文管理**：在 VS Code 中组织和维护章节正文
- **AI 讨论**：围绕剧情设计、人物动机和创作问题进行对话
- **AI 续写**：基于当前章节和相关背景生成续写内容
- **AI 润色**：对已有文本进行语言优化、风格调整和表达增强
- **RAG 上下文检索**：从知识库和正文中检索相关内容，为 AI 输出提供上下文支持

---

## 技术栈

- TypeScript
- VS Code Extension API
- Node.js
- RAG
- DeepSeek API

---

## 项目价值

这个项目体现了我对 **AI Agent 产品体验** 的关注：好的 AI 工具不应该让用户反复解释背景，而应该能进入用户的真实工作空间，理解长期上下文，并在关键任务中提供可控、可追溯的辅助。Novel Agent 尝试把 AI 从外部聊天工具变成写作流程中的上下文协作者。
